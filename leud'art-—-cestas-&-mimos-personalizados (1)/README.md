# 🌿 Leud'Art — Ateliê de Cestas & Mimos Personalizados

> Uma experiência digital informativa, interativa e esteticamente encantadora para o ateliê autoral de **Dona Arleuda**, focada em conexão humana e pedidos diretos via WhatsApp.

---

## 🌟 O Novo Conceito do Site

O site da **Leud'Art** foi totalmente redesenhado para abandonar o formato frio de e-commerce genérico e abraçar uma **boutique de arte e afeto**:

- **Sem fotos convencionais:** Toda a estética é construída com **vetores artesanais sob medida**, padrões orgânicos de trançados, tipografia editorial clássica (*Cormorant Garamond* e *Cinzel*), lacres de cera com relevo tridimensional e paleta de tons terrosos nobres.
- **Simulador Interativo ("Monte seu Mimo em Tempo Real"):** Os visitantes podem experimentar e personalizar suas composições em tempo real (escolhendo a base rústica, o sentimento da ocasião, mimos especiais, cores de fita de linho, inicial gravada no lacre de cera e redação do cartão manuscrito).
- **Conversão Direta para o WhatsApp Oficial:** Ao concluir a composição ou explorar qualquer ocasião, um clique envia todo o resumo formatado para o WhatsApp da proprietária: **(88) 99928-7029**.
- **Sino Zen do Ateliê:** Efeito sonoro meditativo sintetizado diretamente no navegador via Web Audio API.

## 🚀 Como Publicar na Vercel

1. Suba o projeto para o seu repositório Git (GitHub ou GitLab).
2. Conecte o repositório na **[Vercel](https://vercel.com)**:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
3. Pronto! O arquivo `vercel.json` já está configurado para roteamento global e cache instantâneo na CDN da Vercel.
